# 三进制与九卦

三进制以 3 为基数。两位三进制数有 3² = 9 种组合，四位有 3⁴ = 81 种。新易用这两组数给自己的卦系命名，但起点不是把《周易》的八卦改名成九卦。

《周易》的经卦是乾、坤、震、巽、坎、离、艮、兑，共八个。每卦三爻，爻分阴阳，所以是 2³ = 8，不是 9。八个别卦两两相叠，得到 8×8 = 64 个别卦。有的笔记把“九卦”写成“三个爻、阴阳两态、一共八个卦”，那是把八卦和九卦数混在一处。八是二进制三爻的满组合，九来自别处。

新易的九，来自九宫缺中宫这一结构问题，以及作者放入的炁卦。八个经卦占八方，中宫五的位置另立炁卦，基本卦成为九个。九个基本卦两两相叠，得到 9×9 = 81 个六爻卦。其中上下卦都不含炁的，仍是原来的六十四卦；只要上卦或下卦有炁，就落到新增的卦里。81 也可以写成 3⁴。四位、每位三态，和“九乘九”是同一个整数的两种分解，不必当成同一种画卦动作。

西汉扬雄的《太玄》走了另一条三值路。它有八十一首。每首之下有九赞，赞辞共七百二十九条，与 3⁶ = 729 这个数相遇。扬雄是在爻的层面加入中间值。新易应用稿写明，自己不把每一爻都改成恒定的三值，以免直接变成 3⁶ = 729 卦的另一套经文；它保留六爻占断的骨架，只在基本卦里加炁，让含炁的卦在断卦时再落到阴阳。两条路线都碰到 81 这个数，操作不同。

若把阴、炁、阳记成 −1、0、+1，每一位就是一个平衡三进制数字。这便于书写和编程。它还不是量子力学里的 qutrit。qutrit 是可以处于三个正交态相干叠加的物理系统，读出时得到其中一个态。卦爻上的“炁”若被用来表示尚未判定的中间记录，只是在模型里留了一个第三符号。测量、退相干和错误率，要到具体的量子器件上才有定义。

因此，三进制与九卦的文章只承诺三件事：八卦是 8，新易基本卦是 8 加炁，81 是 9² 也是 3⁴。《太玄》的 81 首可以对照，不能算作新易卦名的出处。
