# 二进制与八卦

二进制只用 0 和 1。八卦由三爻组成，每一爻在《周易》里取阴或阳。三条爻、每种两态，组合数是 2³ = 8。六爻卦是两个三爻卦相叠，组合数是 2⁶ = 64。就计数而言，八卦是三位二进制字，六十四卦是六位二进制字。

编码要先规定哪一爻是低位。下文把初爻（最下面一爻）当作最低位，阳为 1，阴为 0。在这个约定下：

| 卦 | 自下而上 | 二进制 |
|---|---|---|
| 坤 | 阴阴阴 | 000 |
| 震 | 阳阴阴 | 001 |
| 坎 | 阴阳阴 | 010 |
| 兑 | 阳阳阴 | 011 |
| 艮 | 阴阴阳 | 100 |
| 离 | 阳阴阳 | 101 |
| 巽 | 阴阳阳 | 110 |
| 乾 | 阳阳阳 | 111 |

巽的三爻自下而上是阴、阳、阳，对应 110。阳、阳、阴则是兑，对应 011。若有人把上爻当作低位，整张表会左右翻转。比较不同书里的“八卦二进制”时，先看低位定在哪一端。

十七世纪末，莱布尼茨与在康熙朝廷的耶稣会士白晋通信，见到先天卦序图，指出阴阳爻的两种取值可以配上他正在阐述的二进制。1703 年他发表二进制算术的说明。这是一次真实的中西符号对照。它没有把伏羲写成二进制计算机的发明人，也没有给出电路、时钟或逻辑门。

新易在这套二值结构旁边增加炁。增加之后，基本卦不再只是 8 个，九宫中宫有了卦名，复卦的计数改走 9×9 = 81。那是另一篇文章里的三进制扩展。本文只把《周易》原有的八卦钉在二值组合上：八个卦名，不多也不少，每一种阴阳排列用尽一次。
